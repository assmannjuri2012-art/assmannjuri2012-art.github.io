# Operation Syndicate: Grand Casino

Free open-world heist game, playable in the browser: **https://assmannjuri2012-art.github.io/**

This repository holds the published website and the browser build of the game
(Godot 4.3, WebGL 2). It is generated by `tools/export_web.sh` of the game's
project; changes made here by hand are overwritten by the next release.
